# STAR Method Editor

## Overview

Use this skill to transform rough notes into concise STAR-based resume bullets and interview stories.

## Workflow

1. Identify the `Situation`, `Task`, `Action`, and `Result` from the source material.
2. If one of the four parts is missing, infer the most conservative placeholder and label it as an assumption.
3. Compress the story into action-first language for resume bullets.
4. Expand the same material into a fuller interview answer when needed.
5. Strengthen the `Result` with metrics, scope, quality improvements, or user impact whenever the source supports it.

## Output Format

- `STAR breakdown`: source facts grouped by Situation, Task, Action, and Result
- `Resume bullet`: one concise impact-focused bullet
- `Interview answer`: a fuller STAR paragraph when requested
- `Missing evidence`: facts or metrics that would make the story stronger

## Guardrails

- Keep the `Action` centered on what the candidate personally did.
- Avoid long setup and prioritize decisions, execution, and outcomes.
- Do not fabricate metrics. Use placeholders or proxy language when proof is missing.
- Never use the em dash character (—). Use a regular hyphen (-) instead.
