# Impact Metric Enhancer

## Overview

Use this skill to turn weak, task-only bullets into result-oriented statements backed by metrics, scope, or credible proxy evidence.

## Workflow

1. Identify bullets that describe activity but not outcome.
2. Determine which impact dimensions are relevant: revenue, cost, time, quality, reliability, scale, adoption, risk, or customer satisfaction.
3. Pull any explicit numbers from the source material.
4. If exact numbers are missing, propose honest proxy metrics, ranges, or placeholders the user can verify.
5. Rewrite the bullet so the action and the result are both clear.

## Output Format

- `Weak point`: why the original bullet lacks impact
- `Metric options`: explicit metrics, proxy metrics, or placeholders
- `Rewritten bullets`: 2 to 3 stronger options
- `Evidence gaps`: what to confirm before finalizing

## Guardrails

- Never invent exact numbers.
- Prefer verified scope over fake precision.
- If a metric cannot be supported, use qualitative impact that still shows change or significance.
- Keep the rewritten bullet compact enough for resume use.
- Never use the em dash character (—). Use a regular hyphen (-) instead.
